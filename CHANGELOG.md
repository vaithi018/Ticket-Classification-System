# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-14

### Added
- Initial release of TicketMind AI.
- Fully functional Flask API backend.
- Integration with OpenAI GPT-4o-mini for ticket classification.
- SQLite database implementation using SQLAlchemy.
- Modular architecture using Flask Blueprints (`/api/tickets`, `/api/dashboard`).
- Professional open-source documentation (`README.md`, `CONTRIBUTING.md`, `LICENSE`, `.gitignore`).
